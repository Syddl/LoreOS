## Old vs new

| Behaviour | Before | After |
|---|---|---|
| A write with no Origin | Passed | 403 |
| A write with a `null` or foreign Origin, or another port | 403 | 403 |
| A write with `Authorization: Bearer …` and no Origin | Passed | Passes the Origin rule. Only the scheme `bearer` (any case) is exempt; `Basic`, `Token` or a bare key get 403. |
| Allowed hosts | Hard-coded `LOCAL_HOSTS` | `settings.allowed_hosts()` |
| Chunked body over the cap | Spooled, then `read(cap+1)` | `BodyLimit` counts bytes in `receive` and raises `HTTPException(413)`. A declared `Content-Length` over the cap still gets 413 before routing. The cap is read per request. |
| 422 | FastAPI's list | `{detail: "question: Input should be a valid string"}` |
| `/api/health` | None | 200 `{status: ok}`; 503 on any error, logged by error class only |
| Startup with a key missing | Starts | Logs each problem at ERROR, then raises `RuntimeError` naming the keys |
| GET on an unknown path | 404 | `api/...` gets a JSON 404; a file in `DIST` is served; anything else gets `DIST/index.html`; with no build, a 404 naming `npm run build --prefix frontend` |
| An unrouted POST | 404 | 405, from the GET catch-all (review row 18) |

**A finding I fixed inside the owned files.** A plain resolve-and-contain check kept files outside `DIST` from being served, but on Windows it still made the server open a network connection. `/%5c%5chost%5cshare%5cx` decodes to the network path `\\host\share\x`, and `resolve()` on it opens an SMB (Windows file-sharing) connection to that host. Any web page can trigger this GET against `127.0.0.1:8000`, and that connection can leak the dev account's NTLM password hash. The fallback now refuses a path with a root, a drive or `..` before touching the filesystem, then still checks that the resolved file is inside `DIST`. The new test `test_a_unc_path_never_reaches_the_filesystem` goes red with the guard removed (checked by hand, then restored).

## Limitations

- `test_documents_api.py::test_unknown_document_is_404` passes only because the fallback answers `/api/documents/<id>` with a JSON 404. 4.4 moves it to a scoped route.
- The Origin rule runs in Starlette's `BaseHTTPMiddleware`. Nothing in 4.1 streams a response, so that is untested.
- A malformed `Content-Length` gets a 500 rather than a 400. uvicorn rejects one before it reaches the app.
- The UNC test only bites on Windows. On Linux the backslashes are a file name inside the build, which is harmless, so CI passes it either way.
- The TestClient never runs startup for the shared fixtures. Startup is covered by its own two tests: one that refuses to start and one that serves.
