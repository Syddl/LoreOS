## Limitations

- **Visual layout is unchecked.** I took no screenshot. The phase 7 browser row ("ask, and open a citation by keyboard") is what proves it.
- **The first red was not an import failure.** The plan expected one, but the 5.2 stub already existed, so the red was a missing label.
- **Whitespace-only questions are still posted.** `required` blocks an empty question, but a question of only spaces is trimmed to `""` and sent. Whatever the server returns is shown as an error.
- **Enter in the question box adds a new line.** Keyboard users submit by tabbing to "Ask". Enter-to-submit was not requested, so I left it out.
- **One Sheet per marker.** Each marker carries its own Sheet, and a Sheet's portal mounts only while it is open. A repeated `[2]` gives two triggers for the same citation, and each returns focus to itself.
