## Old vs new

| Behaviour | Before | After |
|---|---|---|
| Importing a URL | no module | `fetch(url, *, resolve=None, dial=None) -> Fetched(content, kind, url)` |
| Private, link-local, loopback, multicast or IPv4-mapped address | n/a | `Refused` before any dial. Every resolved address must be `is_global` and not multicast, after unwrapping `ipv4_mapped` |
| A name that resolves to no address | n/a | `Refused`, so the empty case fails closed instead of passing `all([])` |
| Where the connection goes | n/a | Each hop gets its own `httpx2.AsyncClient(trust_env=False, follow_redirects=False)`. Its transport's pool is an `httpcore2.AsyncConnectionPool` over `_Pinned`, an `AnyIOBackend` subclass whose `connect_tcp` ignores the host it is given and dials the checked address and port. TLS keeps the URL's host name for SNI and the certificate check (httpcore2 `connection.py` line 136, `self._origin.host`) |
| Redirects | n/a | At most 5. Each `Location` is joined to the current URL, normalised, resolved and checked again. A 6th raises `Refused` |
| Limits | n/a | `asyncio.timeout(TIMEOUT_S)` covers the whole fetch, redirects included, and raises `TimeoutError`. Bytes are counted after decoding from `aiter_bytes()`, and the fetch stops at `MAX_BYTES + 1` with `TooLarge` |
| Status and type | n/a | 4xx and 5xx raise `HTTPStatus` with `.status`. `text/html` and `application/xhtml+xml` map to `html`, `text/plain` to `txt`, `application/pdf` to `pdf`. Any other type raises `UnsupportedContent` naming it |
| A name that does not resolve | n/a | The `socket.gaierror` is wrapped as `httpx2.ConnectError`, so every network failure is a `TransportError`, as the contract says |

The cases cover everything in plan.md 2.4:
- **Refused, with `dial` never called:**

  - mixed public and private;
  - `ftp://`;

- **Redirect to a private name:** refused, after only the first hop was dialled.
- **Redirect count:** 5 redirects are followed and a 6th is refused.
- **Pinned:** `dial` saw `("93.184.216.34", 80)`. With `HTTP_PROXY`, `HTTPS_PROXY` and `ALL_PROXY` set, the fetch still succeeds and dials the checked address.
- **Limits:**
  - a gzip body that inflates to `MAX_BYTES + 1` is `TooLarge`;
  - a slow server with `TIMEOUT_S` patched to 0.25 s raises `TimeoutError`.
- **Status and type:**
  - 404 and 503 raise `HTTPStatus` with that status;
  - `image/png` raises `UnsupportedContent` naming it;
  - html, xhtml, plain and pdf map to their kinds, with the right content and final URL.

A few cases go past the plan's list but test behaviour the task states:
- `224.0.0.1`, because it is `is_global`, so only the multicast check refuses it;
- `empty.test`, the fail-closed case for a name with no address;
- a body of exactly `MAX_BYTES` that passes, to pin the boundary;
- 5 redirects that pass;
- `normalise` on its own: lowercasing, default port dropped, fragment dropped, `/` for an empty path, IPv6 brackets, and refusal of a missing host, a bad port and a broken IPv6 URL.

What the tests do not exercise:
- **HTTPS is never run.** SNI and certificate checking on the host name rest on reading httpcore2's source, not on a test.
- **The proxy case cannot catch a `trust_env` change.** httpx2 ignores environment proxies whenever a transport is passed (`allow_env_proxies = trust_env and transport is None`, `httpx2/_client.py` line 1496). The case goes red only if the custom transport is dropped.
- **Pinning has no red-proof of its own.** Any mutation that breaks pinning would make a real DNS lookup or dial `93.184.216.34`, which the no-network rule forbids.

## Limitations

- **Private attribute.** `_client` replaces `transport._pool`, a private attribute of httpx2 2.13.1, because `AsyncHTTPTransport` takes no network backend. If an upgrade renames it, the default pool would be used instead. The pinned and proxy cases would then go red, since `dial` is never called, so this cannot regress silently.
- **Embedded IPv4.** Only `ipv4_mapped` is unwrapped, as the plan says. NAT64 `64:ff9b::/96` and 6to4 `2002::/16` addresses that embed a private IPv4 address pass: `64:ff9b::a00:1` reports `is_global` True under Python 3.14. Unwrapping them, or refusing those prefixes, would close it.
- **Per-operation timeouts.** httpx2's default 5 s timeouts still apply inside the 10 s budget. A stall of 5 to 10 s raises `httpx2.ReadTimeout`, a `TransportError`, rather than `TimeoutError`. Both count as transient in 3.3's classification.
- **3xx without `Location`.** A 300 or 304 with no `Location` goes on to the type check rather than being treated as a redirect or an error.
- **Proxy address.** For the "unroutable" proxy the test uses a dead local port, `http://127.0.0.1:1`, so that even a regression stays on 127.0.0.1.
- **Decompression.** httpx2's decoder already decompresses in bounded pieces (`ZlibDecompressor`, `MAX_DECODE_CHUNK_SIZE`), so a gzip bomb cannot inflate one chunk without limit before the count sees it.
