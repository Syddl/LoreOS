## Old vs new

| Behaviour | Before | After |
|---|---|---|
| Scoring a run's rows | No metrics module | `summarize` returns `metrics`, `judge_confusion`, `latency_ms` and `counts` per spec behaviour 8 and the plan's row shape |
| A metric with a zero denominator | n/a | `None`, never 0. That covers no answerable rows, no unanswerable rows, no answered answerable row, no graded answer, and no graded calibration pair |
| Citation accuracy | n/a | Pooled: relevant citations over all citations of the answerable, answered rows. A per-question mean is not used |
| Faithfulness and judge agreement | n/a | Count only graded answers and graded calibration pairs. A verdict failure (`grade` or `judge` is None) leaves the denominator and is counted in `judge_errors` or `calibration_judge_errors` |
| `percentile` | n/a | Nearest rank: k = ceil(q * n / 100), at least 1, k-th smallest value; `None` for an empty list. q * n is computed before the division because `7 / 100 * 100` is `7.000000000000001` in floating point, which would ceil to 8 |

The fixture is built so that each plausible mistake gives a different number:

| Mistake | Number it gives | Expected |
|---|---|---|
| Citation accuracy averaged per question | 5/12 | 3/7 |
| Citation accuracy counting the unanswerable q6 | 3/8 | 3/7 |
| Faithfulness counting q4's verdict failure | 3/5 | 3/4 |
| Agreement counting c4's verdict failure | 1/2 | 3/5 |
| MRR taking q2's rank 8 hit instead of rank 4 | lower | 0.37 |
| Recall counting rank 6, or counting source 0 twice | higher | 8/15 |

Rank 5 (recall) and rank 10 (MRR) are each matched at the boundary, so those bounds are inclusive.

## Limitations

- `_recall` divides by `len(row["sources"])` for answerable rows. An answerable row with no sources would raise `ZeroDivisionError`. Task 1.1's validator (sources on exactly the answerable rows) keeps such a row out, and the preflight runs that validator before any run.
- A non-refused row whose `judge` is `None` is counted neither in `judged` nor in `judge_errors`. The row shape says `judge` is `null` only for a refusal. If 2.1's partial-result path ever writes an answered row before judging it, that row drops out of faithfulness without a count. A test in 2.1 over a partial result would show it.
- `percentile` returns the list element itself, so integer inputs give an integer. The run's `search_ms` comes from a timer and is a float.
- The redproof above has not been run. The main session runs it.
